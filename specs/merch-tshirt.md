# Merch by Amazon — t-shirt design spec

## File requirements

- **Dimensions:** 4500 x 5400 px
- **Format:** PNG
- **Background:** transparent
- **Color profile:** sRGB
- **Resolution:** 300 DPI
- **Max file size:** under 25 MB

## Design rules

- Design only — **no mockups**, no t-shirt photo, just the artwork on transparency.
- Keep important elements within a safe area (avoid edges getting cut on print).
- High-contrast, legible text. Merch designs live or die on readable typography.

## Trademark / copyright (critical)

Merch by Amazon bans accounts for trademark/copyright violations. Rules of thumb:

- **No** brand names, logos, slogans, characters, artists, teams, or franchises.
- **No** common trademarked phrases (many everyday phrases are registered).
- Original concepts only.

Claude will screen each phrase with reasoning + a web check, but this is **not**
legal clearance — it cannot query the official USPTO trademark database from this
environment. Treat it as a strong first filter, not a guarantee.
