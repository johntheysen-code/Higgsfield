# Pinterest data (demand signal)

Drop Pinterest research CSV exports here (e.g. from PinTwist).

This is the **demand** side: what people are searching, saving, and engaging with.

## Ideal columns (don't worry if some are missing)

- `keyword` / `search_term` — the term searched
- `pin_title` — title of the pin
- `saves` / `repins` — save count (interest signal)
- `engagement` — likes/comments if available
- `date` — when the row was captured
- `url` — link to the pin (optional)

Any CSV works — I'll adapt to whatever columns your tool exports. Just drop the
file in this folder and tell me it's here.
